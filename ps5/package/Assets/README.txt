Skate 3 for PS5 - the game's files go here.

Recomp Store sets this folder up for you, from your own copy of the game
(an ISO) and its Title Update 3.

By hand: copy the files of your own copy of Skate 3 (Xbox 360) into this
folder - default.xex and the data folder, side by side - and put the
Title Update 3 file (TU_12K2276_000000C000000.00000000000O3) here too. The
app sets the update up the first time it starts.

  /data/homebrew/PPSA93003/Assets/default.xex
  /data/homebrew/PPSA93003/Assets/data/...
  /data/homebrew/PPSA93003/Assets/TU_12K2276_000000C000000.00000000000O3

DLC: put your DLC packages in a "dlc" folder here
(/data/homebrew/PPSA93003/Assets/dlc/). They're installed when the game
starts.

No game files come with this app: you need your own copy of the game.
